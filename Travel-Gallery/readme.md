
# Travel Gallery

## Project Description
Travel Gallery is a responsive website that displays beautiful travel destinations using image cards. It allows users to explore different places through a simple and attractive gallery layout.

## Features
- Responsive travel gallery layout
- Header and navigation section
- Sidebar with destination categories
- Six destination cards:
  - Goa
  - Ooty
  - Jaipur
  - Munnar
  - Kochi
  - Shimla
- CSS Grid-based image layout
- Responsive design for desktop, tablet, and mobile screens
- Goa card spans two columns on desktop view

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
