
# Responsive Pricing Page

## Project Description
The Responsive Pricing Page is a website that displays different subscription plans with their prices and features. It helps users compare pricing options through a clean and responsive card-based layout.

## Features
- Three pricing plans:
  - Basic - ₹499
  - Pro - ₹999
  - Premium - ₹1,999
- Highlighted Pro plan
- Pricing cards with plan details
- Responsive card layout
- CSS Grid using auto-fit and minmax()
- Flexbox for arranging card content
- Mobile-friendly design

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Media Queries
