
# Responsive Dashboard Layout

## Project Description
The Responsive Dashboard Layout is an admin dashboard interface designed to display important business statistics and information in an organized layout.

## Features
- Admin dashboard interface
- Sidebar navigation
- Statistics cards:
  - Users
  - Sales
  - Orders
  - Profit
- Two illustrative bar-chart panels
- CSS Grid for dashboard layout
- Flexbox for arranging elements
- Responsive design for smaller screens
- Mobile layout using CSS media queries

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## Project Structure
```text
dashboard/
│

```

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
